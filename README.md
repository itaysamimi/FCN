# FCN – הענן המשפחתי שלנו

ענן פרטי לשימוש המשפחה בלבד: פתקים, קבצים ותמונות.
בנוי על Next.js, ‏Supabase ו-Cloudflare R2, ומתארח ב-Vercel.

## הרצה מקומית

1. העתיקו את `.env.example` ל-`.env.local` ומלאו את הערכים.
2. התקינו תלויות:
   ```bash
   npm install
   ```
3. הריצו את שרת הפיתוח:
   ```bash
   npm run dev
   ```
4. פתחו את http://localhost:3000 בדפדפן.
